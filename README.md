## Project Overview

Handwritten Digit Recognition is a deep learning-based application that identifies handwritten digits from uploaded images using a trained MNIST model.

The application processes the input image, detects the handwritten digit(s), and provides the predicted result along with the prediction confidence.

## Machine Learning Workflow

1. Load the MNIST dataset
2. Preprocess the handwritten digit images
3. Normalize the pixel values
4. Train the deep learning model
5. Evaluate the trained model
6. Save the trained model
7. Load the model into the Streamlit application
8. Upload a handwritten digit image
9. Preprocess the uploaded image
10. Predict the digit using the trained model
11. Display the prediction and confidence
